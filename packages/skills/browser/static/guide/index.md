How to do a task on the web for the user with this skill. It has research (search, look) and a real browser with a tab per chat (open, read, act, login, and call with the tab's session). The library skill keeps what's worth running again, and calls APIs with the user's keys: prefer it whenever it can do the task.

Topics (guide with topic):
- `route`: picking the way to do a task.
- `research`: finding out how a service works.
- `browser`: clicking through a site well.
- `logins`: signing in, codes and passkeys, which only the user gives, and handing the tab over to them.
- `safety`: what never to do.
