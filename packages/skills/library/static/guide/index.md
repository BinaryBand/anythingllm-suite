The library is the user's own set of API toolkits: one per service, each with what you learned of its API, the keys it calls with, and small JavaScript functions you wrote that call it. A function runs again on request, or on a schedule, so the next time a task is one step.

The library is being built: only guide works so far. Don't promise the user a toolkit yet.

Topics (guide with topic):
- `functions`: how a function is written: main, its input, and what kit offers it.
- `snippets`: worked examples to adapt (guide with snippet).
